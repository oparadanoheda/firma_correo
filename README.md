# Generador de firmas de correo · CEIPSO Filósofo Séneca

Página web autocontenida (un solo archivo HTML) para que el personal del centro cree su firma de correo con la imagen corporativa.

- Se rellenan **nombre**, **correo electrónico** y, opcionalmente, **cargo**.
- La vista previa se actualiza en directo.
- **Copiar firma** copia la firma con formato para pegarla en el correo de EducaMadrid (Roundcube).
- Si al pegar hay problemas, hay un plan B para pegarla como **código HTML**.
- Incluye una guía paso a paso con capturas de Roundcube.

Los logos se cargan desde la web del centro: <https://site.educa.madrid.org/cp.seneca.madrid/>

## Uso

Abre `generador-firma.html` en el navegador, o la versión publicada en GitHub Pages.
